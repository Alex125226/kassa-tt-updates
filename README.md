# Каса ТТ — оновлення

Тут лежать оновлення програми «Каса ТТ». Каси перевіряють їх самі кожні 2 години,
завантажують у фоні й встановлюють **після закриття зміни**.

| Випуск | Для кого | Адреса |
|---|---|---|
| `demo` | демо-версія (Kassa-TT-DEMO) | `releases/download/demo` |
| `stable` | робоча версія на ТТ | `releases/download/stable` |

У кожному випуску три файли: установник `.exe`, `.blockmap` і `latest.yml`.
Каса дивиться у `latest.yml`: якщо там версія новіша за встановлену — оновлюється.

Вихідного коду програми тут немає — лише установники.
